# OP-025 – BattleTrack WebApp

## Goal

Build a web application for ROK BattleTrack.

Core flow:

Google Sheets -> Google Apps Script -> Governor ID lookup -> Personal dashboard

## Initial milestones

1. Establish project structure.
2. Connect the existing BattleTrack Google Sheets.
3. Resolve a Governor ID to a player record.
4. Return a structured data object to the frontend.
5. Build the BattleTrack dashboard.
6. Add KvK and performance views.
7. Deploy as a Google Apps Script WebApp.
