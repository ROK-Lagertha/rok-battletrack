# BattleTrack Data Model

The final data model will be mapped to the existing 3903 tracking sheets.

Planned high-level areas:

- Governor identity
- Power
- Kill Points
- T4 kills
- T5 kills
- Deads
- DKP
- KPR
- Performance / requirements
- KvK history

Exact sheet names, columns and mappings are intentionally not assumed here.
